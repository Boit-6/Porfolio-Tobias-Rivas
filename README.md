# Portfolio de Tobias Rivas

Sitio personal: sobre mí, educación, habilidades, experiencia, proyectos y CV descargable. En español e inglés, con tema claro y oscuro.

Hecho con HTML, CSS y TypeScript, sin frameworks.

## Desarrollo

```bash
npm install
npm run build   # compila src/script.ts a dist/script.js
```

Después se abre `index.html` en el navegador.

## CV

Los PDF salen de `cv/cv-es.html` y `cv/cv-en.html`:

```bash
npm run cv      # necesita Google Chrome
```
